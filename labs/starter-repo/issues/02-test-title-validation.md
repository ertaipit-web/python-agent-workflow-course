# Issue 02: закрепить проверку пустого названия тестами

## Задача

Добавить regression tests для контракта `create_task`: название обрезается по краям, а пустое или состоящее из пробелов название отклоняется.

## Критерии приёмки

- Тест подтверждает trimming непустого названия.
- Параметризованный тест подтверждает `ValueError` для пустой строки и пробелов.
- Production-код не меняется.

## Границы

- Разрешён только `tests/test_core.py`.
- Проверка: `python -m pytest`.
