# Issue 05: сохранить порядок при фильтрации

## Задача

Добавить regression test, подтверждающий, что фильтр возвращает подходящие задачи в том же порядке, в котором они были переданы.

## Критерии приёмки

- Тест использует несколько задач с совпадающими и несовпадающими статусами.
- Проверяются состав и порядок результата.
- Production-код не меняется, если тест проходит.

## Границы

- Разрешён только `tests/test_core.py`.
- Проверка: запустите pytest по platform-specific команде из [README проекта](../README.md).
