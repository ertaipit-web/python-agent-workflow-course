# Учебный репозиторий курса

Для практики в этом же репозитории есть небольшой самостоятельный Python-проект `labs/starter-repo/`. Он не является частью Zensical-сайта и имеет собственные зависимости и тесты.

В нём подготовлены 5 issue: изменение поведения с baseline-тестом, тестовая задача, документационная правка, неоднозначный запрос и regression edge case. Инструкция находится в `labs/starter-repo/README.md`, упражнения — в `labs/starter-repo/exercises/`.

## Как получить файлы

- Если репозиторий уже клонирован, откройте `labs/starter-repo/` в корне checkout-а.
- Если вы читаете опубликованный сайт, откройте исходный GitHub-репозиторий курса, выберите **Code → Download ZIP**, распакуйте архив и перейдите в `labs/starter-repo/`.

Учебный проект можно открыть отдельно в VS Code, но для изменений курса и лабораторных достаточно одного клона. Submodule не нужен: материалы и упражнения меняются вместе с программой курса.

Для общего окружения курса из корня репозитория установите тестовую зависимость и запустите suite:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".\labs\starter-repo[dev]"
.\.venv\Scripts\python.exe -m pytest .\labs\starter-repo\tests
```

Если учебный проект скопирован отдельно от курса, создайте для него собственное окружение `.venv` по инструкциям в его README.
