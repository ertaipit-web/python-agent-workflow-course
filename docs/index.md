# Практикум мультиагентных систем на Python

### Практикум по мультиагентной разработке на Python

## Для кого этот курс

Для Python-разработчика, который уже регулярно использует AI coding tools (например, Kilo Code, Claude Code или похожие IDE-агенты) и хочет перейти от одиночных запросов к проверяемым мультиагентным workflow и ограниченно автономным coding agents.

**Нужны:** уверенное чтение и изменение Python-кода, Git на уровне веток/diff, запуск pytest или аналогичных проверок, базовое понимание HTTP/JSON и готовность разбираться в логах и конфигурации.

**Не требуется заранее:** опыт с LangGraph, Ollama, MCP или построением агентов — эти вещи вводятся по ходу. **Курс не рассчитан на абсолютного новичка в программировании и не является курсом no-code/вайбкодинга с нуля.**

Здесь проектируется не просто набор промптов, а управляемая система агентов: с ограниченными ролями, проверяемыми передачами данных, правами, тестами, журналированием и понятными условиями остановки.

## Маршрут обучения

1. [Основной курс: мультиагентная разработка на Python](course.md) — 8 недель, ориентировочно 24–40 часов на обязательное ядро (3–5 часов в неделю); расширения увеличивают нагрузку. Kilo можно использовать для baseline; Ollama и LangGraph не обязательны.
2. [Продвинутый трек: автономные агенты](autonomous-agents.md) — каталог из 6 модулей; общий фундамент и ещё 1–2 модуля на выбор. Ориентир — 3–5 часов на выбранный модуль (примерно 6–15 часов всего); дополнительные расширения и эксперименты потребуют больше времени.
3. [Быстрый справочник: Ollama, VS Code и Kilo](ollama-vscode.md) — короткая настройка и диагностика.
4. [Подробная лабораторная по локальной модели](local-models.md) — настройка под ориентир 14 ГБ RAM, команды Ollama, подключение к двум чатам и API smoke tests.
5. [Источники и материалы для дальнейшего изучения](sources.md) — учебные программы, документация фреймворков и инструкции по локальным моделям, использованные при подготовке курса.
6. [Учебные репозитории и задания](lab-repository.md) — Taskboard для базового прохода и Repo Triage для практики с issue и реальным устройством Python-репозитория.

Оценка времени ориентировочная: скорость зависит от опыта, выбранного provider-а и объёма экспериментов. Она не включает отдельное освоение новых инструментов или настройку локальной модели. Курс начинается с baseline coding agent и безопасного учебного репозитория; локальную модель можно подключить позже, а тесты workflow запускать с mock provider-ом. Облачный API не обязателен. Для локального запуска приведены стартовые настройки под ориентир 14 ГБ RAM, однако фактическая производительность зависит от CPU, GPU/VRAM, контекста и одновременно запущенных приложений.

## Принципы

- Начинать с измеримого baseline одного coding agent и добавлять роли только там, где они улучшают результат.
- Описывать вход и выход каждого этапа контрактом, валидировать структуру программно.
- Разделять генерацию кода, исполнение инструментов и разрешение на побочные действия.
- Работать в тестовом репозитории или отдельном worktree; проверять diff и тесты.
- Ограничивать циклы, сохранять состояние и останавливаться на неоднозначности.
- Измерять качество end-to-end, а не полагаться на уверенный тон модели или LLM-as-judge.

## Ожидаемый итог

После основного курса у вас будет Python-оркестратор, который может разбирать issue, делегировать анализ независимым ролям, предложить изменения, запускать разрешённые тесты и собирать отчёт. Если пройти факультативный продвинутый трек, вы дополнительно научитесь строить долгие возобновляемые workflow и проверять ограниченную автономию в sandbox. Доступ к публикации и другим необратимым действиям остаётся под контролем разработчика.
