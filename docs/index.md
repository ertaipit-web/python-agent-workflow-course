# Мультиагентная разработка на Python

Продвинутый практикум для разработчика, который уже пишет на Python и пользуется AI coding tools. Здесь проектируется не просто набор промптов, а управляемая система агентов: с ограниченными ролями, проверяемыми передачами данных, правами, тестами, журналированием и понятными условиями остановки.

## Маршрут обучения

1. [Основной курс: мультиагентная разработка на Python](course.md) — 8 недель. Архитектуры, Kilo Code, Ollama, интеграция с VS Code, Python-оркестратор, tool calling, eval и итоговый проект.
2. [Продвинутый трек: автономные агенты](autonomous-agents.md) — ещё 6 недель. Планирование на длинном горизонте, память, динамическая делегация, восстановление workflow, симуляция и ограниченная автономия.

Курс начинается с локальной модели и безопасного учебного репозитория. Облачная модель не обязательна. Для локального запуска приведены стартовые настройки под ориентир 14 ГБ RAM, однако фактическая производительность зависит от CPU, GPU/VRAM, контекста и одновременно запущенных приложений.

## Принципы

- Начинать с измеримого baseline одного coding agent и добавлять роли только там, где они улучшают результат.
- Описывать вход и выход каждого этапа контрактом, валидировать структуру программно.
- Разделять генерацию кода, исполнение инструментов и разрешение на побочные действия.
- Работать в тестовом репозитории или отдельном worktree; проверять diff и тесты.
- Ограничивать циклы, сохранять состояние и останавливаться на неоднозначности.
- Измерять качество end-to-end, а не полагаться на уверенный тон модели или LLM-as-judge.

## Ожидаемый итог

По завершении обоих треков у вас будет Python-оркестратор, который может разбирать issue, делегировать анализ независимым ролям, предложить изменения, запускать разрешённые тесты и собирать отчёт. Доступ к записи/публикации остаётся под контролем разработчика; автономность наращивается постепенно и тестируется на искусственных отказах.
